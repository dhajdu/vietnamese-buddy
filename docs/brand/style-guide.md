## Typography

- **Heading font:** Plus Jakarta Sans (Google Fonts), 600 weight for display, 500 for titles. Stand-in for Airbnb Cereal, which is proprietary. Headings sit at 20–28px, never heavier than 700.
- **Body font:** Plus Jakarta Sans, 400 weight, 16px base (14px for secondary copy).
- **Monospace font:** JetBrains Mono — for code snippets only.
- **Line height:** 1.5 for body, 1.2–1.25 for headings and titles, 1.43 for 14px captions.
- **Letter spacing:** 0 by default; -0.4px on 22px+ display sizes.
- **Radii:** 8px inputs, 14px cards, 32px / pill (9999px) buttons and search bars. No hard corners on interactive elements.
- **Shadows:** soft and low: `0 6px 16px rgba(0,0,0,0.12)` on floating cards, `0 1px 2px rgba(0,0,0,0.08)` on resting elements.

## Visual style (for UI and image generation)

**Overall mood:** Warm, friendly, generous whitespace on a clean white canvas. One brand color (coral #FF385C) does all the work; everything else is neutral grey.
**Image style:** Photography-driven and human: real people, real places, natural light. Rounded 14px corners on every image. No abstract 3D renders, no clip-art.
**Composition rules:**
- Photography carries the page; keep typography modest (500/600 weights) and let images and whitespace do the heavy lifting.
- Pill-shaped primary controls (search, CTA) are the focal element on any hero.
- Cards sit on white with a soft hairline (#EBEBEB) or a low shadow, never a heavy border.

**Color usage in visuals:**
- Primary brand color is dominant
- Maximum 3 colors per image
- Avoid gradients: solid coral on white, grey neutrals only

## Content formats

**Blog posts:**
- Length: (e.g. 1,200–1,800 words)
- Structure: (e.g. Hook → Problem → Framework → Story → CTA)
- Opening: (e.g. Start with a specific story or surprising fact — never a definition)
- CTA: (e.g. End with one CTA — link to the free consultation booking page)

**Email:**
- Subject line: (e.g. Curiosity gap style, no emojis, under 50 characters)
- Body length: (e.g. 150–250 words — short and scannable)
- Sign-off: (e.g. "— {Founder name}")

**Social posts:**
- LinkedIn: (e.g. Professional hook + 3–5 short paragraphs + question at end)
- Twitter/X: (e.g. Single insight in under 240 chars — thread only for step-by-step content)

---

## What to avoid (all formats)

- Buzzwords: synergy, disruptive, game-changer, leverage (the verb), ecosystem
- Weak hedges: "I think", "It seems", "Perhaps"
- Filler intros: "In today's fast-paced world…", "In this blog post, we will…"
- Passive constructions where active is possible
