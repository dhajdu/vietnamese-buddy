Three consequences

1. Set the paid daily cap to three, not five and certainly not twenty. One situation a day is the premise of the product, so three is already triple the intended use, and it is the only cap that stays solvent on Opus. Configurable in admin either way.

2. Move generation to Claude Sonnet 5 unless a quality test says otherwise. At $9.99 you no longer need it to be profitable at normal use, but it is the difference between an annual heavy user costing you $2.63 and earning you $2.77. The admin test harness makes this measured rather than a guess.

3. Free tier stays at three lessons a week, costing $1.30 a month on Opus and 52 cents on Sonnet, against no revenue.

Voice is not in these numbers yet. FPT bills per character, a lesson runs to about 1,200 Vietnamese characters, and it is synthesised once and cached forever, so it is a one-time cost per lesson. Confirm the rate once the service is activated and fold it in. Adjust is a full-price second generation, which is why it becomes pro-only and counts against the daily cap.

2Ground truth

Verified 12 September 2026 against main.

  • The app lives at /, /lessons, /flashcards, /vocabulary, /progress. Every route sits behind auth via proxy.ts. There is no public page except login and signup.
  • profiles holds id, display name, timezone, created date. No email, no role, no plan.
  • createLesson enforces a hard-coded DAILY_LIMIT of 20 against AI lessons in the last 24 hours.
  • Voice spans five files, a storage bucket, and a pre-warm hook. Re-tested 12 September: FPT.AI still returns 403 because the service was never activated, so every play falls back to browser speech. The code is fine; the account needs switching on.
  • “Vietnamese Daily” appears in 13 files: the wordmark, SEO metadata, three auth pages, and the docs.
  • Stripe is not installed. Scaffold leftovers (app/chat, api/sessions, api/notifications, api/upload) are unused and untouched here.

Why not keep the app at the root and swap by auth state: the root page is the one Google indexes and the one a paid ad lands on. It should be static, fast, and identical for everybody. Swapping content by cookie makes it dynamic, uncacheable, and awkward to test variants against later.

A signed-in visitor who lands on / sees the marketing page with Continue learning → in place of Start free, rather than being bounced. That is one conditional in the header.

The cost is mechanical: roughly 25 internal links and redirects move under /app, plus the auth callback default and the proxy matcher.

4Data model additions

One migration. Three new tables, three new columns.

profiles gains

ColumnPurpose
emailBackfilled and set by the signup trigger, so admin can list and search without reaching into auth.users
is_adminBoolean, default false. Set by hand in SQL for the first admin
stripe_customer_idUnique, set on first checkout

app_settings

A single row, pinned by a check constraint: the two limits, the active Stripe Price ids for monthly and annual, and the AI provider and model. Readable by any signed-in user, writable only by admins.

Prices live here rather than in environment variables because a Stripe Price is immutable: changing what you charge means creating a new Price and pointing at it. Holding the id in settings makes that a dropdown instead of a deploy, and existing subscribers stay on the Price they signed up to, which is both correct and free grandfathering.

model_tests

One row per admin model test: provider, model, situation, pass or fail, latency, token counts, the lesson itself, and any error. This is what turns “try a cheaper model” into a decision you can look at rather than a hunch you act on.

subscriptions

One row per user: Stripe subscription and price ids, status, plan, period end, cancel flag, and a comped boolean so you can grant access without Stripe. A user reads their own row; only the service role writes.

stripe_events

Event id, type, received time. Webhook idempotency: insert first, skip on conflict.

Entitlement is derived, never stored

A user is pro when their subscription row is active or trialing, or when comped is true. Otherwise free. No cached flag to drift out of sync with Stripe.

Freemium gate PR 3

one day

Migration for settings and subscriptions. A single getEntitlement() helper returns the plan, the week’s usage, both limits, and whether the next lesson is allowed. The week starts Monday in the learner’s own timezone, reusing the existing local-date helper.

createLesson calls it first and returns an upgrade prompt instead of a generic error. Home shows “2 of 3 free lessons left this week” under the input, and an upsell card once the week is spent.

Adjust becomes pro-only. On a free account the button carries a lock and opens the upgrade sheet instead of the note field. On a pro account it spends one lesson from the daily cap, because it is a full-price generation. The action re-checks entitlement on the server; the locked button is a courtesy, the guard is the rule.

Adjust gets a progress bar. Today it shows one line of text while a forty-five second call runs, which reads as a hang. Pull the progress card already used by the create form into a shared component — echoed input, animated bar, rotating status lines — and use it in both places. Adjust names what is happening: rewriting the phrases with your note, keeping the grammar pattern, checking it still sounds Southern.

Done when a free account gets exactly the configured number each week and a clear upgrade path on the next attempt, Adjust is locked on free and works on pro, the same progress card appears for create and adjust, a comped account is unlimited to the daily cap, and changing the setting in the database changes behaviour with no deploy.

Admin PR 4

two days

A requireAdmin() guard as the first statement of every admin page and action, matching the rule the Edge8 codebase already enforces. Three screens: a table of every signup with email, join date, plan, lessons, words, streak and last active; a per-learner detail page with comp and un-comp buttons and a link to their Stripe customer; and a settings page in four parts.

Limits: free lessons a week, paid lessons a day. Pricing: two dropdowns listing the live Prices pulled from the Talent Edge Stripe account, so you pick rather than paste an id; a note says changes affect new checkouts only. Discount codes: a read-only list of active promotion codes with percentage, redemptions and expiry. Codes are created in the Stripe dashboard, which already does the whole job.

Model, and this is the part worth care. A free-text model field is a foot-gun, because generation depends on structured output and plenty of models cannot do it reliably. So it is a dropdown of known-good options with a custom string behind an advanced toggle and a warning. Three providers: Anthropic, OpenAI, and OpenRouter, which opens the door to open-weight models. The OpenRouter provider matches the installed AI SDK and Zod versions, so it is one dependency and a third branch in the generator.

Test model is the important half. It runs one golden situation through the selected provider without touching a learner’s data, then shows the rendered lesson, whether it passed the schema, latency, token counts and the cost per lesson, and records the run. Two models can be compared on the same situation. Nothing changes what learners get until you explicitly save. Expect most open-weight models to fail on one of two axes, structured output or Southern Vietnamese with correct diacritics; the harness tells you which, in about a minute.

The first admin is set by hand in SQL. Security notes for review: the service-role client never enters a client component, every action re-checks the guard rather than trusting the page, and admin routes carry noindex.

Done when signed in as Dave the list shows every signup with live numbers, and a non-admin gets a 404 rather than a redirect that confirms the route exists.

Stripe PR 5

two days

The lazy-client pattern lifted from edge8-web: live key in production, test key everywhere else. Two products in the Talent Edge account, $9.99 a month and $79 a year, a 34 percent saving. Their Price ids live in settings, not environment variables, so admin can switch them later.

Three routes: checkout creates or reuses the Stripe customer, reads the active Price from settings, turns on promotion codes so your discounts work, and returns a session URL; the webhook verifies the signature against the raw body and is idempotent through the events table; the portal route hands cancellation and card updates to Stripe so we build no billing UI of our own. Four events matter: checkout completed, subscription updated, subscription deleted, payment failed.

Test mode first, end to end, with the Stripe CLI forwarding to localhost. Live keys only after a test subscription has been created, cancelled, and correctly reflected.

Done when a test card moves a free account to pro within seconds, a promotion code visibly reduces the total at checkout, cancelling in the portal sets the cancel flag, and entitlement follows in both directions.

Marketing site PR 6

two days

One page at the root plus a pricing page, on the existing ĀRCA tokens. Eight sections: hero with the free CTA; the problem shown as textbook Vietnamese beside what Saigon actually says; three steps with the real interface; a real lesson rendered from an actual seed file, not a mock-up; what accumulates over thirty days; pricing read live from settings so the page can never drift from what Stripe charges; five FAQ questions marked up as schema; and a closing call to action.

6The Neil Patel lens, applied

Taken from the Edge8 brand profile and applied to this page rather than described.

Keyword realism

“Vietnamese Buddy” is a brand term. It belongs in the H1 and the schema, not the title tag. What a person actually types:

learn conversational Vietnamese Southern Vietnamese lessons how to speak Vietnamese in Ho Chi Minh City Vietnamese phrases for daily life
KeywordWhy it is winnable
learn conversational Vietnamese (primary)Intent matches the product. The head term is owned by Duolingo and Pimsleur
Southern Vietnamese lessonsLong tail with almost no dedicated competition, and exactly what this is
how to speak Vietnamese in Ho Chi Minh CityQuestion format wins AI Overviews, and matches expats who convert
Vietnamese phrases for daily lifeFits the situation-based structure of every lesson

Title tag against H1

Split them, because the H1 carries no searchable keyword.

Title tag
Learn Conversational Southern Vietnamese — Daily Situation-Based Lessons
H1
Learn the Vietnamese people actually speak in Saigon
Meta
Learn conversational Southern Vietnamese through daily lessons built around your real situations: ordering, dating, work, Grab rides. Three free lessons a week. No textbook Vietnamese.

The rest of the lens

  • Intent to CTA. Every keyword above belongs to somebody who would start a free trial today, not to a browser researching languages in general.
  • Links. Five internal minimum: pricing, sample lesson, FAQ, signup, how it works. Descriptive anchors, never “click here”.
  • Entity definitions. One clean sentence each for Southern Vietnamese, situation-based learning, and spaced review, so a language model can quote the page.

The five FAQ questions, marked up as schema

  1. How is Southern Vietnamese different from Northern Vietnamese?
  2. Can I learn Vietnamese without studying grammar first?
  3. How much Vietnamese do I need to live in Ho Chi Minh City?
  4. Is Vietnamese Buddy free?
  5. What makes situation-based lessons better than a fixed curriculum?

9Decisions

Decided · 12 Sep

Talent Edge LLC collects the money

Use the Talent Edge block from the Edge8 environment file, the one beginning 51RPj3, which already carries a test secret and both webhook secrets. Not the AI Officer Institute block that follows it under the same variable names. Both products get created in the Talent Edge dashboard.

Starting point

How many free lessons a week?

The plan assumes three. It is configurable from day one, so this is a starting position rather than a commitment.

Decided · 12 Sep

$9.99 a month, $79 a year

A 34 percent annual saving, sitting level with Praktika and below Babbel, Speak and Pimsleur. Discounts run as Stripe promotion codes, created in the dashboard and accepted at checkout. Both prices are switchable from admin without a deploy.

Not planned

Do you want a trial?

A seven-day full-access trial converts better than a permanent free tier, but it costs about 28 cents per signup on Sonnet and needs a card up front. Not in this plan; worth a decision.
